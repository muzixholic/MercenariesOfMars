# 화성의 용병단 — 확정할 수치와 계산식

점검일: 2026-10-18. **이미 사용자가 정한 규칙**, **현재 코드의 임시·기본 동작**, **앞으로 결정할 내용**을 구분했다. 아래 미정 항목에 임의의 수치나 새 공식을 적용하지 않았다.

## 1. 이미 정해져 있어 다시 결정할 필요가 없는 기본 규칙

| 항목 | 확정된 규칙 / 범위 |
|---|---|
| 전투 턴 | 아군 턴 → 적군 턴 |
| 파일럿 | 레벨 1~99, 공격·방어·명중·회피 1~999 |
| 기체 기본 HP | 1,000~9,999,000 |
| 기체 기본 EN | 10~990 |
| 기체 기본 장갑·조준·운동성 | 10~9,990 |
| 이동력 | 1~99 |
| 기체 가격 | 0~9,999,000 |
| 허용중량 | 0~990, 무장 총중량이 허용중량 이하일 때 장착 |
| 개조 항목 | HP·EN·장갑·조준·운동성·무장 6종 |
| 개조 효과 | 단계마다 **기본값의 5%** 가산. 복리 아님. 무장 공격력은 장비한 기체의 무장 개조 단계 사용 |
| 개조 상한 | 기본 10. 캠페인 시작값 설정 가능, 스크립트로 증가 가능 |
| 무장 개조 비용 | 0→1은 5,000, 1→2는 10,000… 목표 단계 × 5,000 |
| 나머지 개조 비용 | 0→1은 3,000, 1→2는 6,000… 목표 단계 × 3,000 |
| 방어 / 회피 대응 | 방어는 피해 절반, 회피는 피격률 절반. 반격은 무장을 선택 |
| 탄수 | 최대 탄수 0이면 잔탄 제한 없음. 양수일 때만 잔탄 계산 |
| 매각 | 이번 구현에서는 보류. 구매만 제공 |

기체 범위는 현재 코드에서 **개조 전 기본값의 입력 범위**로 적용한다. 개조 후 최종값도 같은 상한을 지켜야 한다는 결정은 별도로 필요하다.

## 2. 가장 먼저 결정할 전투 계산식

| 번호 | 결정 항목 | 현재 코드 | 확정할 내용 |
|---|---|---|---|
| 전투-1 | 목표 전투 길이 | 별도 목표 없음. 현재 기체 HP 1,000에 무장 공격력 7~17 | 동급 일반 적 1기를 몇 회 명중으로 격추할지, 보스는 몇 회인지. 피해 수치와 보상 설계의 기준 |
| 전투-2 | 최종 피해 | `max(1, 파일럿 공격 + 개조 적용 무장 공격 - 파일럿 방어 - 피격 칸 방어 보정)` | 파일럿 공격을 단순 가산/배율 중 어떻게 반영할지. 기체 장갑과 파일럿 방어의 분담·계수. 무장 1,000 이상과 파일럿 1~999의 상대적 영향 |
| 전투-3 | 최종 명중률 | `clamp(파일럿 명중 + 무장 명중 보정 + 공격 칸 명중 보정 - 파일럿 회피, 0, 100)` | 조준치 10~9,990와 파일럿 명중 1~999를 백분율로 변환하는 방법. 상대 운동성·회피 결합 방식. 차이식/비율식·기준 명중률·계수 |
| 전투-4 | 운동성·회피 | 파일럿 회피만 명중률에서 차감. 기체 운동성 미사용 | 운동성과 회피의 비중. 어떤 수치 조합이 50%/100% 명중에 해당하는지 |
| 전투-5 | 피해·명중 상하한 | 최소 피해 1, 최종 명중 0~100%, 피해는 대상 잔여 HP까지만 실제 차감 | 최소 피해 1 유지 여부, 명중 0/100% 허용 여부, 피해 변화폭/크리티컬을 도입할지. 크리티컬은 필수 요구가 아닌 선택 사항 |
| 전투-6 | 지형 보정 단위 | 명중은 %p 가산, 방어는 고정 수치 차감 | 새 장갑 공식에서도 방어를 고정값으로 쓸지/비율로 쓸지. 피격 지형 회피·엄폐 항목 추가 여부 |
| 전투-7 | 정수·소수점 처리 | 일반 피해는 정수. 방어 피해는 `ceil(일반 피해 / 2)`. 회피 명중률은 소수점 0.5까지 유지 | 새 피해·명중 계산의 절사/반올림/올림 위치. ‘절반’ 자체는 확정됐으므로 끝자리 처리만 결정 |
| 전투-8 | EN·탄수 소비 | 실행한 공격/반격마다 EN 비용과 1발 소비. 빗나가도 소비. 선제 격추로 반격 불발 시 미소모 | 이 소비 규칙 유지 여부. 다단 공격이나 여러 발을 쓰는 무장을 만들면 발수·비용을 어떻게 설정할지 |
| 전투-9 | 중량의 효과 | 장착 가능 여부에만 사용. 명중·회피·이동에는 영향 없음 | 중량을 단순 제한으로 유지할지, 적재율에 따라 운동성/이동력 보정을 줄지 |

현재 소규모 피해 예: 공격 10·무장 10·상대 방어 3·지형 보정 0이면 피해 17이다. HP 1,000의 적을 격추하려면 반격·회복 등을 제외하고 **59회 명중**이 필요하다. 현재 수치 규모를 그대로 두고 장갑만 합산하면 피해가 최소값에 몰릴 수 있으므로 새 공식을 먼저 정해야 한다.

## 3. 경험치·성장·적군 레벨

| 번호 | 결정 항목 | 현재 코드 | 확정할 내용 |
|---|---|---|---|
| 성장-1 | 기본 격추 경험치 | 적의 기본 격추 경험치 데이터·지급 없음 | 적 파일럿/기체/배치 중 어디에 기본값을 둘지, 일반·정예·보스의 기본값 |
| 성장-2 | 지급 대상·시점 | 미구현 | 마지막 격추자만/피해 기여 분배/출격자 공유. 반격 격추, 목표 도달 승리, 전투 중 이탈 처리. 즉시 지급/정산 때 지급 |
| 성장-3 | 필요 경험치 | 미구현. 현재 필드는 누적 경험치 | 레벨별 필요 경험치 곡선 또는 표, 레벨 99 도달 총량, 초과 경험치 유지, 한 번에 여러 레벨 상승 처리 |
| 성장-4 | 레벨 차 보정 | 미구현 | 고레벨 적 추가 보상/저레벨 적 감소 여부, 배율·하한·상한. 누구의 레벨과 비교할지 |
| 성장-5 | 능력치 성장 | `t=(레벨-1)/98`, `반올림(Lv1값+(Lv99값-Lv1값)×선택 커브(t))`, 결과 1~999 | 파일럿별 Lv1·Lv99 능력치와 네 능력치의 커브 배정. 일반·에이스 능력치 격차 |
| 성장-6 | 적군 자동 레벨 | `반올림(실제 출격 아군 평균 레벨 × 배율 + 보정)`, 프리셋 범위와 1~99 제한 | 평균에 강제 출격·저레벨 증원·대기 인원을 어떻게 포함할지. 현재는 전투 생성 시 실제 배치된 모든 아군을 포함하고 대기 인원 제외 |
| 성장-7 | 적군 프리셋 수치 | 일반 `평균×1+0`, 정예 `평균×1.05+1`, 보스 `평균×1.1+2`, 모두 1~99 | 이 값들을 정식 난이도로 확정할지, 스테이지별 최소/최대 레벨, 자동 레벨 비활성 적의 예외 |
| 성장-8 | 적군 경험치 보정 | 함수는 `max(0, 반올림(기본 경험치×경험치 배율+가산))`. 현재 3종 모두 ×1+0 | 일반·정예·보스 보정값, 레벨 차 보정과 적용 순서. 지급 기능 연결 필요 |

성장 커브는 레벨 상승에 따라 감소하지 않는 0~1 커브이며, 시작 0·끝 1로 검증한다. 반올림은 0.5 올림 방식이다. 현재는 경험치가 증가해도 자동으로 레벨이나 능력치가 바뀌지 않는다.

## 4. 자금·가격·수리·보급

| 번호 | 결정 항목 | 현재 코드 | 확정할 내용 |
|---|---|---|---|
| 경제-1 | 격추 보상 | 기체 가격 데이터는 있으나 수입 미연결 | `기체 가격 × 격추 보상률`인지 별도 보상액인지. 개조 반영 여부·보스 가산·반격 격추도 동일 보상인지 |
| 경제-2 | 미션 보수 | 없음 | 스테이지 기본 보수, 추가 목표 보상, 클리어 턴·손실에 따른 가감. 엔딩 직전에도 정산할지 |
| 경제-3 | 수리비 | 없음. 다음 전투 HP 최대값 | 잃은 HP 비율 기준/격추 시에만/정액. 기체 기본 가격과 개조 후 가치 중 기준. 수리비 부족 시 대처 |
| 경제-4 | EN·탄약 보급 | EN은 다음 전투 최대값, 잔탄은 에셋 시작값으로 복원 | 무료 전량 보급/유료 사용량 보급/실제 잔량 이월. 기본 시작 탄수와 최대 탄수의 관계 |
| 경제-5 | 기체 구매가 | 기체 가격을 그대로 차감. 현재 모든 기체 가격 0 | 실제 품목별 가격, 기본 무장 포함 가격 유지 여부. 반복 구매를 허용하면 기체별 보유 개체 ID 필요 |
| 경제-6 | 무장 구매가 | 별도 구매 가격을 그대로 차감. 현재 전부 0 | 품목별 가격·탄약 포함 여부·동일 무장 복수 구매 수량/재고 제한 |
| 경제-7 | 파일럿 영입비 | 별도 영입 가격 1회 차감. 현재 전부 0 | 일시 영입비만 쓸지, 미션별 급여/계약료도 둘지. 후자는 현재 없음 |
| 경제-8 | 경제 흐름 | 시작 자금 500,000, 구매·개조로 감소만 함 | 미션당 기대 수입, 평균 수리·보급 지출, 몇 미션마다 몇 단계 개조할 수 있어야 하는지 |
| 경제-9 | 매각 | 사용자 결정으로 보류 | 이번 확정 대상에서 제외. 재개 시 매각률·개조비 반환·무장 자동 분리 등을 정함 |

미션 정산식은 아직 없다. 필요한 항목을 확정한 뒤 `종료 자금 = 시작 자금 + 격추 보상 + 미션 보수 + 추가 보상 - 수리비 - 보급비 - 기타 비용`처럼 지급·차감 순서까지 정해야 한다. 이것은 설계 대상의 구조 예시이며 구현된 공식이 아니다.

## 5. 개조·상한·반올림

| 번호 | 결정 항목 | 현재 코드 | 확정할 내용 |
|---|---|---|---|
| 개조-1 | 기본값과 최종값의 상한 | 입력 기본값만 기체 범위로 제한. 개조 후에는 더 커질 수 있고 정수 최댓값에서 제한 | HP 9,999,000·EN 990 등의 범위를 개조 후 최종값에도 적용할지 |
| 개조-2 | 5%의 정수 처리 | `기본값 + floor(기본값×단계/20)` | 현재 절사 유지 여부. 예: EN 10의 1단계는 10, 2단계는 11이므로 일부 단계에서 표시 수치가 그대로일 수 있음 |
| 개조-3 | 상한 해금 계획 | 시작 상한 10, 스크립트 증가 가능. 10 초과도 같은 효과·비용 공식 | 캠페인 어느 시점에 몇 단계까지 해금할지, 최종 최대 단계 |
| 개조-4 | 적 개조 상한 | 전투 생성 시 캠페인 상한이 적 기체의 적용 단계에도 전달됨 | 아군 연구 상한과 적 기체 개조 허용 상한을 공유할지 |

현재 구현된 효과식은 사용자 예시와 일치한다. 무장 1,000을 5단계 기체에 장착하면 1,250이다. 0→n 총비용은 무장 `5,000×n(n+1)/2`, 기타 항목은 각각 `3,000×n(n+1)/2`다. 0→10은 무장 275,000, 기타 각 165,000이며 6종 전체는 1,100,000이다. 이 비용 공식을 새로 제안한 것이 아니라 기존 확정 규칙을 합산한 것이다.

## 6. 이동·맵·행동 관련 수치

## 7. 현재 AI에 들어 있는 임시 판단 기준

- 적 공격: 이번 턴 공격 가능 여부 → 사거리와의 차이 → 이동 비용 → 기대 피해 → 대상 잔여 HP → EN 비용 순으로 선택한다. 공격 가능한 칸 중에서는 이동 비용이 기대 피해보다 먼저 비교된다.
- 적 대응: 전투 불능 위험이 낮은 선택 → 상대 격추 확률이 높은 선택 → 효용이 큰 선택. 효용은 `예상 반격 피해 - 예상 피격 피해 - 예상 EN 소비 × 0.1`이다.
- EN 가중치 0.1은 코드 기본값으로, 사용자가 확정한 밸런스 수치로 취급하지 않는다. 현재 대응 효용에는 잔탄 희소성·미션 목표·후속 적의 공격이 들어가지 않는다.
- 최종 피해 규모가 커지면 같은 EN 가중치의 영향은 상대적으로 작아진다. 전투 공식 확정 후 성향별 가중치·자원 보존 기준을 정할 대상이다.

## 8. 빠르게 결정할 순서

1. 동급 일반 적 격추에 필요한 평균 명중 횟수와 초반 무장 공격력 규모.
2. 피해 공식의 공격·장갑·방어 비중, 명중 공식의 조준·명중·운동성·회피 비중.
3. 레벨 99까지의 필요 경험치, 기본 격추 경험치, 지급 대상·시점.
4. 격추 보상·미션 보수·수리비·보급비와 품목 가격.
5. 최종 개조 상한·최종 능력치 상한·절사 정책.
6. 지형 유형·사선·자원 회복 규칙과 AI 가중치.
