# 화성의 용병단 — 미구현·모호한 동작·설정 점검

점검일: 2026-10-18. 현재 C#과 안내 문서를 대조하고 Unity CLI로 실제 에셋을 읽어 확인했다. 코드·데이터·씬·프리팹은 수정하지 않았다. 이 문서와 별도의 [수치·계산식 결정 목록](수치와_계산식_결정목록_2026-10-18.md)만 작성했다.

이번 점검은 구현·데이터 확인이며 새 플레이 테스트나 빌드 검증을 수행하지 않았다. 직전 구현의 테스트 결과와 이번 읽기 전용 점검을 구분한다. 아래의 ‘미구현’에는 앞으로 필요할 확장도 포함되며, 모두 과거 요청의 누락이라는 뜻은 아니다.

## 1. 우선순위가 높은 미구현

| 우선순위 | 항목 | 현재 상태 | 남은 작업 |
|---|---|---|---|
| 1 | 기체·파일럿 전투 수치 결합 | HP·EN·이동력·무장 개조는 적용. 피해는 파일럿 공격/방어, 명중은 파일럿 명중/회피를 사용. 기체 장갑·조준·운동성은 표시만 함 | 합산/배율 등 최종 계산식을 결정한 뒤 전투 예측·판정·AI에 공통 적용 |
| 1 | 장갑·조준·운동성 개조의 전투 효과 | 비용은 차감하고 표시 수치도 오르지만 판정에는 사용하지 않음 | 계산식 도입 전까지 해당 개조를 허용할지도 결정. 현재는 실제 전투 이득 없이 자금 지출 가능 |
| 1 | 경험치 획득·자동 레벨업 | 경험치 저장·표시, 성장 커브, 적군 경험치 보정 계산 함수는 존재 | 기본 격추 경험치, 지급 대상·시점, 레벨 차 보정, 필요 경험치 표, 실제 누적·레벨업 연결 |
| 1 | 자금 수입과 전투 정산 | 시작 자금과 구매·개조 지출만 연결 | 격추 보상·미션 보수·추가 목표 보상·수리/보급 비용과 결과 정산 화면. 현 코드에는 전투로 자금을 늘리는 경로가 없음 |
| 1 | 기체 이동 유형 | 지상·공중·우주 속성은 저장·표시 | 지형/맵 환경 대응, 이동 가능 여부·비용·구조물 통과 판정에 연결 |
| 2 | 손상·EN·탄수의 전투 간 관리 | 새 전투마다 HP·EN은 최대값, 탄수는 무장 에셋의 현재 탄수로 재생성 | 자동 회복 정책인지 실제 손상/잔탄 이월인지 결정하고 캠페인 상태·저장에 연결 |
| 2 | 수리·보급·복구 | 인터미션에 해당 기능 없음. 턴마다 자동 EN 회복·재장전도 없음 | 무료 자동 보급/유료 보급/전장 보급 중 정책 결정. 전 무장 소진 시 진행 방안 필요 |
| 2 | 전투 연출 제작 도구 | 공격→피해→반격→피해 재생, 시간·색·크기·효과 프리팹 설정은 있음. 기체는 임시 캡슐 | 전용 연출 에디터, 실제 기체 모델/모션·발사 위치·카메라·음향 편집 |
| 2 | 미션 조건과 이벤트 확장 | 승리: 적 전멸 또는 목표 칸 도달. 패배: 아군 전멸. 이벤트: 인트로/아웃트로/출격 준비/아군 구역 점유 시 1회 | 필요하면 특정 기체 격추·호위·방어 턴·시간 제한·턴 시작/격추 트리거 추가 |
| 3 | 적 AI의 전술 성향 | 이동/사거리/기대 피해를 이용한 단기 행동, 생존을 우선한 대응 선택 | 장기 우회·목표 지점 방어·호위·집단 전술·보스 성향·잔탄 보존 설정 |
| 보류 | 매각 | 사용자 결정에 따라 구매만 구현 | 매각은 새 승인·설계가 생길 때 진행. 현재 미완료 오류로 보지 않음 |

## 2. 구현돼 있지만 정책 확정이 필요한 부분

| 항목 | 현재 실제 동작 | 결정해야 할 내용 |
|---|---|---|
| 기체 템플릿과 보유 개체 | 같은 기체 에셋은 캠페인에서 1개만 보유. 기체 중복 구매 불가, 파일럿도 동일 | 동일 모델 기체를 여러 대 소유할지. 필요하면 모델 데이터와 보유 기체 개체 ID를 분리해야 함 |
| 동일 무장 복수 장착 | 같은 무장은 여러 개 구매·여러 기체에 배분 가능. 한 기체에는 같은 무장 에셋 1개만 장착 | 동일 총 2정, 동종 미사일 포드 복수 장착을 허용할지. 장착 슬롯·탄수 개체 관리와 연관 |
| 아군 영구 이탈의 범위 | 파일럿 기준으로 현재 편성을 영입 목록·전장에서 제거. 이 편성의 기체·장착 무장을 대기 재고로 반환하는 처리는 없음 | 파일럿만 이탈인지, 기체·장비를 가지고 떠나는지. 기존 ‘현재 전투에서도 즉시 제거’ 결정은 유지 |
| 대기 파일럿의 이탈 | `RemoveAlly`는 편성된 영입 목록에서만 대상 파일럿을 찾음 | 구매 후 미배정 파일럿도 스크립트 이탈 대상이어야 하는지. 현재는 대기 파일럿 제거 경로가 별도로 없음 |
| 영입과 전장 증원 | 영입 이벤트는 캠페인 명단에 추가. 실행 중 전장에 새 유닛을 생성하지 않음 | 전장 증원이 필요하면 위치·유닛 ID·행동 가능 여부를 갖는 별도 증원 명령 필요 |
| 단순 탑승 해제 | 파일럿 교환/대기 파일럿 배정/미탑승 기체 배정은 가능. 탑승자만 내려 대기시키는 전용 버튼은 없음 | ‘파일럿 해제’ 메뉴가 필요한지 |
| 격추된 아군의 취급 | 영입 목록에서 영구 제거하지 않음. 다음 전투에서 다시 초기 상태로 생성 | 영구 손실·기체만 손실·수리비 지불·파일럿 부상 중 정책 결정 |
| 공격의 시야 판정 | 상하좌우 거리만 판정. 구조물은 이동을 막지만 사선을 막지 않음 | 벽 너머 사격, 간접 공격, 고저차·엄폐를 도입할지 |
| 지형 명중 보정 | 공격자가 선 칸의 명중 보정을 적용. 피격자 칸은 방어력 보정만 제공 | 숲의 효과를 명중 증가로 볼지, 피격률 감소/엄폐로 볼지. 현 구조에는 별도 지형 회피 보정이 없음 |
| 반격 제한 | 사거리·EN·탄수만 충족하면 가능. 이전 이동/행동완료 기록과 이동 후 사용 불가 제한은 반격에 적용하지 않음 | 현 규칙을 정식 규칙으로 유지할지, 반격 전용 제한이 필요한지 |
| 공격 실패 자원 소모 | 빗나가도 EN·탄수 소모. 확인 취소 시 미소모, 선제 격추로 반격 못 하면 반격 자원 미소모 | 현 규칙을 확정 규칙으로 문서화할지 |
| 출격 제한 | 스테이지 선택 출격만 차단. 맵 지정 고정·강제 출격은 별도 적용 | ‘모든 출격 금지’가 필요하면 현재 선택 제한과 구분할지 |
| 생존 분기의 대상 | 파일럿 ID가 아니라 맵 유닛 ID로 생존 판정. 선택 출격 칸에 누구를 넣었는지에 따라 의미가 달라짐 | 특정 파일럿/기체 생존 조건을 별도로 제공할지 |
| 상점 해금 유지 | 완료 스테이지의 목록만 사용. 조건은 현재 플래그/보유 상태로 재평가. 스테이지 간 자동 누적 없음 | 영구 해금 공통 목록이 필요한지. 현재는 이후 스테이지에 같은 해금 조건을 재등록해야 함 |
| 저장 범위 | 인터미션 3슬롯·타이틀 불러오기. 전투 중 저장·자동 저장·자동 백업 복원 UI 없음 | 중단 저장/미션 진입 자동 저장/백업 불러오기 필요 여부 |
| 데이터 수정 후 저장 호환 | GUID 참조와 개조·장착·레벨·경험치 등 상태를 저장. 기본 능력치/가격/무장 수치는 에셋에서 다시 읽음 | 배포 후 밸런스 수정의 기존 저장 반영 여부, 세이브 버전 이전 정책 |
| 조작·설정 | 마우스/키보드 중심. 음량·격자·전투 연출 설정 | 게임패드·키 변경·해상도·전체화면 등은 필요 여부를 별도 결정. PS풍 외형만으로 게임패드 지원이 되는 것은 아님 |

## 3. Unity CLI로 확인한 실제 데이터 설정

현재 데이터에는 캠페인 1개, 스테이지 3개, 맵 2개, 기체 6개, 파일럿 16개, 무장 8개가 있다. 각 스테이지·맵·기체 장비·파일럿 성장·무장에 대한 기존 검증 함수의 오류 목록은 비어 있었다. 검증 오류가 없다는 것이 밸런스나 콘텐츠가 완성됐다는 뜻은 아니다.

| 확인 항목 | 현재 값 | 의미 |
|---|---|---|
| 기본 캠페인 | 기동 → 발동 → 엔딩, 시작 자금 500,000, 초기 아군 2기, 개조 상한 10 | 진행 경로는 연결됨. 별도 ‘현재 전투’ 스테이지는 단독 엔딩이며 기본 경로에 포함되지 않음 |
| 스테이지 분기 | 3개 모두 조건별 분기 0개 | 기능은 구현됐으나 실제 분기 시나리오는 미작성 |
| 상점 등록 | 캠페인 공통 목록과 3개 스테이지 기본·조건부 목록 모두 0개 | 상점 기능은 동작하지만 현재 데이터로는 판매할 품목이 없음 |
| 구매 가격 | 기체 6개·파일럿 16개·무장 8개 모두 0 | 등록하면 무료 구매. 품목 가격을 사용자가 설정해야 함 |
| 기본 맵 선택 출격 | 선택 칸 2개, 초기 아군 2기 모두 고정 출격, 나머지 선택 후보 0기 | 강제 2기 외 선택 출격은 현재 0기. 선택 배치를 시험하려면 고정 배치 또는 영입 명단을 조정해야 함 |
| 전투 수치 규모 | 기체 HP는 모두 1,000, 기존 무장 공격력 7~17 | 기체 HP만 메카닉 규모로 커지고 무장은 기존 소규모 수치라 전투가 길어질 수 있음. 새 공식과 함께 재조정 필요 |
| 무장 중량·탄수 | 8개 모두 무게 0·최대 탄수 0 | 현재 모든 무장은 중량 부담과 잔탄 제한 없음. 중량/탄수 기능을 실제 콘텐츠에서 체감할 설정은 미작성 |
| 시각 데이터 | 기체 6개 모두 맵 아이콘 없음. 무장 8개 모두 아이콘·개별 연출 프로필 없음 | 임시 표현/기본 효과 사용. 파일럿 10명은 포트레이트가 각각 1개 연결됨 |
| 파일럿 밸런스 | 생성한 10명은 모두 레벨 1·경험치 0·초기 공격10/방어3/명중100/회피1 | 이름·약력·이미지 차이는 있지만 초기 전투 능력의 개별화는 미작성. 성장 커브 연결은 되어 있음 |
| 적 경험치 보정 | 일반·정예·보스 모두 배율 1·가산 0 | 서로 다른 보정값은 아직 설정하지 않음. 실제 지급 기능도 미연결 |

이 항목들은 자동으로 채우거나 수정하지 않았다. 테스트용 ‘새 캐릭터’ 이름의 기체 2개는 무장도 비어 있으므로 실제 사용 여부를 확인한 뒤 이름·장비를 정리할 대상이다. 이름이나 비어 있는 무장만으로 삭제 대상으로 확정하지는 않는다.

## 5. 다음 작업 권장 순서

1. 목표 전투 길이·피해/명중 공식·수치 규모 확정. 장갑/조준/운동성 개조를 전투에 연결한다.
2. 경험치 지급/레벨업과 전투 자금 정산을 구현한다. 캠페인의 성장·소비가 순환하도록 만든다.
3. 격추·수리·보급·이탈 시 자원 보존 정책과 기체 복수 보유 여부를 확정한다. 저장 구조 변경 전에 결정하는 편이 좋다.
4. 지상/공중/우주 통행과 엄폐/사선 규칙을 구현한다.
5. 현재 2개 미션에 판매 목록·가격·무장·분기·선택 출격을 실제로 설정하여 짧은 캠페인으로 검증한다.
6. 전투 연출 에디터와 정식 모델·이미지·음향을 붙이고, 중복된 초기 문서를 통합한다.
