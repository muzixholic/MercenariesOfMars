# 프로젝트 정리 기록

작업일: 2026-10-20.

## 삭제한 미사용 데이터

다음 파일럿은 이름이 ‘새 캐릭터’이고 약력·포트레이트가 비어 있는 초기 자동 생성 데이터였다. 원래 테스트 편성은 다른 파일럿을 참조하고 있었다. Unity `AssetDatabase.GetDependencies`로 저장 참조 목록을 제외한 모든 Assets의 의존성을 확인한 뒤 삭제했다.

- `Assets/파일럿/테스트_아군_1_파일럿.asset`와 `.meta`.
- `Assets/파일럿/테스트_아군_2_파일럿.asset`와 `.meta`.
- 위 파일을 담던 빈 `Assets/파일럿` 폴더의 메타데이터.

삭제 전 파일은 Git에서 제외되는 `작업결과/정리백업_2026-10-20/`에 복사했다. 제작용 파일럿 30명, 기존 예제 파일럿, 편성 템플릿은 보존했다.

## GUID를 유지해 이동한 데이터

| 원래 위치 | 정리 위치 |
|---|---|
| `Assets/테스트_아군_1.asset` | `Assets/MercenariesOfMars/Data/유닛편성/테스트_아군_1.asset` |
| `Assets/테스트_아군_2.asset` | `Assets/MercenariesOfMars/Data/유닛편성/테스트_아군_2.asset` |
| `Assets/아군 기사 (시라유키 미유).asset` | `Assets/MercenariesOfMars/Data/유닛편성/아군 기사 (시라유키 미유).asset` |
| `Assets/아군 궁수 (키리시마 란).asset` | `Assets/MercenariesOfMars/Data/유닛편성/아군 궁수 (키리시마 란).asset` |
| `Assets/기체/테스트_아군_1_기체.asset` | `Assets/MercenariesOfMars/Data/기체/테스트_아군_1_기체.asset` |
| `Assets/기체/테스트_아군_2_기체.asset` | `Assets/MercenariesOfMars/Data/기체/테스트_아군_2_기체.asset` |

`AssetDatabase.MoveAsset`로 이동했고 각 파일의 이동 전후 GUID가 동일함을 검사했다. 맵에서 참조하는 테스트 편성과 기체를 삭제하지 않았다. 이동 후 비어 있는 `Assets/기체` 폴더의 메타데이터만 제거했다. 정식 편성 템플릿은 현재 맵 참조가 없어도 에디터에서 사용자가 선택할 제작 데이터로 보존했다.

## 기존 미커밋 작업 반영

- 기체·파일럿을 먼저 선택하는 유닛 편성 작성 도구와 필요할 때만 신규 데이터 생성.
- 기체 범위, 6종 개조 효과·비용, 캠페인별 개조 상한과 스크립트 해금.
- 영입·이탈, 출격 선택 제한, 조건부 배치, 강제 편성 알림·유지, 영입 명단에서 선택 출격.
- 기체·무장·파일럿 구매, 무장 창고·중량 검사, 파일럿 교환, 인터미션 공방.
- 인터미션 저장·불러오기와 저장 참조 목록 생성 도구.
- 스테이지별·조건부 판매 목록과 다음 미션 출격 수 미리보기.
- 발키리 파일럿 10명과 포트레이트 이미지·연결 데이터.
- 관련 Editor/PlayMode 회귀 테스트와 사용 안내.

이미 커밋된 해태·네뷸라 파일럿은 그대로 유지했다. 매각·경험치 지급·새 전투 계산식 등의 미정 기능은 이번 정리에서 구현하거나 값을 임의로 지정하지 않았다.

## 보존 및 문서 정리

씬·프리팹, 렌더 파이프라인 설정, Input System 에셋, Resources에서 불러오는 데이터, 에디터 도구·마이그레이션·테스트 코드는 보존했다. 씬에 직접 참조되지 않는다는 이유만으로 제작용 데이터나 메뉴 진입점을 삭제하지 않았다.

README에 실행 방법·폴더 구성·안내 문서 링크를 추가했다. 기존 기본 안내에서 반격 없음·균일 이동 비용·플래그 저장 없음·인터미션 기능 미구현 등 현재 코드와 모순되는 설명을 갱신했다. 이전 기능 점검과 계산식 결정 목록은 점검 당시 기록임을 표시해 `문서/`에 보존했다.

`Library/`, `Temp/`, `Logs/`, `UserSettings/`, 로컬 백업과 검증 결과는 기존 `.gitignore` 규칙에 따라 커밋하지 않는다.
