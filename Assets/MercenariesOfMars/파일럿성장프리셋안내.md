# 파일럿 성장·적군 레벨 설정

## 범위와 성장 계산

- 파일럿 레벨: **1~99**.
- 공격력·방어력·명중력·회피력: 각각 **1~999**.
- 파일럿 에디터에서 **1레벨 기본값**, **99레벨 목표값**, **각 능력치의 성장 커브 프리셋**을 지정한다. 목표값은 기본값 이상으로 제한한다.
- 능력치 = 반올림(기본값 + (목표값 − 기본값) × 해당 레벨의 성장 커브 값).
- 같은 레벨은 언제나 같은 값이며, 레벨업마다 증가분을 누적하지 않는다. 전투 시작 시 현재 레벨로 계산한 수치를 복사한다.
- 프리셋 미지정 시 모든 레벨에서 기본값을 사용한다. 파일럿 에디터의 미리보기 레벨 슬라이더로 결과를 확인한다.

누적 경험치는 계속 저장·표시한다. **경험치 획득, 필요 경험치 표, 경험치에 따른 자동 레벨업은 아직 없다.** 현재는 편집한 파일럿 레벨 또는 적군 자동 레벨을 성장 계산에 사용한다. 기체 장갑·조준·운동성을 합산하는 새 전투 계산식은 미정이다. 인터미션 구매·개조와 비용 차감은 구현됐고, 격추 보상·수리비·매각은 연결하지 않았다.

## 성장 프리셋 설정 메뉴

Unity 메뉴 **화성의 용병단 → 설정 → 파일럿 성장 프리셋**을 연다.

| 기본 프리셋 | 특징 |
|---|---|
| 선형 성장 | 레벨에 비례해 일정하게 증가 |
| 초반 성장형 | 중간 레벨에서 전체 성장량의 약 70%에 도달 |
| 후반 성장형 | 중간 레벨에서 전체 성장량의 약 30%에 도달 |

프리셋 하나에는 성장 커브 하나만 설정한다. 파일럿 에디터의 공격력·방어력·명중력·회피력 성장 커브 항목에서 각각 다른 프리셋을 선택하거나 같은 프리셋을 공유할 수 있다. 미지정한 능력치는 기본값을 유지한다. X축은 레벨 위치(0=1레벨, 1=99레벨), Y축은 전체 성장량의 비율(0~1)이다. 시작 0·끝 1이고, 정수 레벨 99개에서 감소하지 않아야 한다. 잘못된 커브는 편집기와 전투 편성 검증에서 안내한다.

**새 프리셋 추가 / 선택 복제 / 등록 해제**를 지원한다. 추가·복제 시 저장할 에셋 위치를 고른다. 등록 해제는 설정 목록에서만 제외하며, 이미 연결된 파일럿의 프리셋 에셋은 삭제하지 않는다. 이름과 목록 순서를 바꾸어도 기존 연결은 에셋 참조로 유지된다.

**기본값·등록 목록** 탭에서 새 파일럿의 기본 성장 프리셋을 정한다. 기본값을 바꾸어도 이미 만들어진 파일럿의 개별 선택은 바뀌지 않는다. 새 파일럿의 초기 99레벨 목표값은 기본값+98(999 상한)로 제공하며 자유롭게 조정한다.

## 적군 레벨 보정 설정 메뉴

**화성의 용병단 → 설정 → 적군 레벨 보정 프리셋**을 연다.

계산식: **반올림(출격 아군 평균 레벨 × 배율 + 보정)**. 결과를 프리셋의 최소·최대 레벨 및 전역 1~99로 제한한다. 0.5는 올림한다.

| 기본 프리셋 | 배율 | 보정 | 출격 평균 20일 때 |
|---|---:|---:|---:|
| 일반 | 1.00 | 0 | 20 |
| 정예 | 1.05 | +1 | 22 |
| 보스 | 1.10 | +2 | 24 |

배율·보정·최소·최대 레벨과 **격추 경험치 배율·가산값**을 수정하고 프리셋을 추가·복제·등록 해제할 수 있다. 평균 레벨 미리보기로 결과를 확인한다. **기본값·등록 목록** 탭에서 공통 기본 적군 프리셋을 지정한다.

맵 에디터 **배치 → 유닛 배치** 항목에서 **적군 자동 레벨**과 **적군 레벨 보정**을 지정한다. 보정 미지정 시 공통 기본값을 사용한다. 자동 레벨을 끄면 파일럿에 작성한 레벨을 사용한다. 이 옵션은 적군에만 적용하며 아군은 파일럿 레벨을 사용한다. 같은 적 기체·파일럿을 배치별로 일반·정예·보스로 다르게 쓸 수 있다.

평균은 이번 전투에 배치된 아군 유닛들의 파일럿 레벨 기준이다. 벤치·미출격 파일럿은 포함하지 않는다. 동일 파일럿 정의를 여러 아군 유닛에 연결했다면 배치된 각 유닛을 한 명으로 센다. 전투 시작 시 평균과 적군 레벨·능력치를 한 번 계산하고 전투 중에는 고정한다. 원본 파일럿 레벨·경험치는 수정하지 않는다. 아군이 없는 경우 자동 보정을 적용하지 않으며, 정상 전투는 기존처럼 양 진영 배치가 필요하다.

## 기본 데이터와 기존 파일럿

공통 설정은 `Assets/MercenariesOfMars/Resources/MercenariesOfMars/성장설정.asset`에 저장한다. 기본 성장 3종과 적군 보정 3종도 같은 폴더에 저장한다. 설정 창은 최초 생성 후 기존 프리셋을 덮어쓰거나 사용자가 등록 해제한 항목을 다시 만들지 않는다.

기존 파일럿에는 선형 성장을 연결했다. 현재 레벨에서의 능력치를 보존하도록 필요하면 기본값과 목표값을 역산한다. 다만 이전 0 능력치는 새 하한 1로, 범위 밖 수치는 새 범위로 제한한다. 현재 프로젝트의 기존 파일럿은 1레벨이므로 기본값+98의 초기 목표값을 사용한다.

추가 씬·프리팹 연결은 필요 없다. 전투 진행기의 성장 설정이 미지정이면 공통 설정을 자동으로 읽는다. 필요할 때 해당 컴포넌트의 성장 설정에 별도 설정 에셋을 연결해 사용할 수 있다.

## 경험치 보정과 이번 변경

격추 경험치 = 반올림(기본 격추 경험치 × 경험치 배율 + 경험치 가산값), 범위 0~정수 최댓값. 기본 배율 1·가산값 0으로 보상을 유지한다. 설정 창에서 기본 격추 경험치를 입력해 보정 결과를 미리 본다. 기존 파일럿의 누적 경험치에는 곱하지 않는다.

배치별 적군 보정 프리셋이 우선하며 미지정 시 공통 기본값을 쓴다. 자동 레벨이 꺼져 있거나 출격 아군이 없어도 경험치 보정은 적용된다. 전투 유닛에 보정값을 복사해 전투 중 에셋 수정에 영향받지 않는다. `BattleUnit.CalculateDefeatExperience(기본 경험치)`로 보정 결과를 얻는다. 경험치 지급·필요 경험치·자동 레벨업은 아직 구현하지 않았다.

기존 파일럿의 공통 성장 연결은 능력치별 연결로 이전하며 1~99레벨의 계산 결과를 확인한다. 이전 프리셋에서 능력치별 커브가 달랐다면 별도 단일 커브 프리셋으로 보존한다. 기존 프리셋의 이름·GUID는 유지한다.

이번 변경 파일: `Runtime/PilotGrowthPreset.cs`, `Runtime/PilotDefinition.cs`, `Runtime/EnemyLevelPreset.cs`, `Runtime/PilotProgressionSettings.cs`, `Runtime/BattleSession.cs`, `Runtime/CharacterDefinition.cs`, `Editor/PilotProgressionEditors.cs`, `Editor/PilotProgressionSetup.cs`, `Editor/MechPilotEditors.cs`, 신규 `Editor/PilotGrowthMigration.cs`, 두 성장 관련 테스트 파일, 파일럿 4개 에셋과 프리셋 에셋, 이 안내서. 씬·프리팹 변경과 추가 Inspector 연결은 없다.
