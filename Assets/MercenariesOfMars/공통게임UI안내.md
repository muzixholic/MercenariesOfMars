# 공통 고전 전술 UI

무장 선택창의 회색 입체 패널·남색 제목줄·파란 선택 강조를 나머지 게임 화면에도 적용했다. 저장된 씬·프리팹·편성 데이터는 수정하지 않는다.

## 적용 화면

- 타이틀, 승리·게임 오버: 중앙 작전 패널과 파란 주 동작 버튼. 일반 전투는 다시 시작·타이틀 복귀, 맵 테스트의 승리·패배는 종료만 제공한다.
- 유닛 행동: 유닛 오른쪽에 이동·공격·대기·능력을 표시한다. 이동 불가 상태의 버튼 제한과 메뉴 밖 클릭·Esc 취소는 유지한다.
- 작전 메뉴: 빈 칸 우클릭 시 현재 라운드·설정·턴 종료·닫기를 표시한다.
- 설정: 격자, 전투 연출, 음량 조절. 설정은 기존처럼 현재 실행 중에 적용한다.
- 전투 대응: 중앙 패널에서 대응을 선택한다. 반격 무장은 공격과 동일한 무장 선택창에서 파일럿·기체 상태와 무장 표, 상세 정보를 확인한다. 적 공격 범위·공격자·대상 표시는 유지한다.
- 전투 확인: 공격측·대응측을 항상 같은 폭(5:5)으로 나란히 비교한다. 긴 기체명·무장명은 줄바꿈하고 세로 스크롤을 사용한다. HP·EN·명중률·피해·선택 무장·잔탄·대응을 표시한다.
- 상세 능력: 기체·파일럿 정보, HP·EN 막대, 무장 목록을 구획으로 나눈다.
- 대사: 남색 이름표와 회색 본문 패널. 포트레이트, 클릭·Space·Enter 페이지 넘김을 유지한다.
- 턴 전환·공격자 표식·전투 연출의 정보 패널과 건너뛰기 버튼도 같은 테마를 사용한다.

HP는 빨강, EN은 파랑이다. 전투 계산식·탄수 소비·적군 판단·이벤트 진행 규칙은 변경하지 않는다. 메뉴의 기본·호버 글자색을 통일해 회색 배경에서 읽기 쉽게 하고, 버튼은 호버·포커스·눌림 시 파란색으로 강조한다.

## Inspector 설정

추가 연결은 필요 없다. 기존 전투 진행기의 글꼴 항목 표시명을 **공통 게임 UI 글꼴**로 변경했다. 저장 필드명은 유지하므로 이미 지정한 글꼴도 보존된다. 미지정하면 기존 무장 선택창과 같은 시스템 한글 글꼴을 사용한다. 배포 환경까지 글꼴을 고정하려면 프로젝트에 포함한 한글 Font를 지정한다.

무장 선택창은 기존 Canvas를 유지하고, 나머지 메뉴에는 기존 입력·표시 구조 위에 공통 테마를 적용한다. 공통 색상과 글꼴 선택 로직을 공유하며 Linear 색 공간에서도 색상이 일치하도록 처리한다. UI 텍스처·글꼴은 실행 중 생성하고 종료 시 정리한다. 에디터 제작 도구의 UI는 변경하지 않는다.

## 변경 파일

`Assets/MercenariesOfMars/` 기준이며 새 파일의 Unity 메타데이터를 포함한다.

- 신규 `Runtime/TacticalGuiTheme.cs`: 공통 팔레트·글꼴·입체 테두리·메뉴 제목줄·버튼·자원 막대, GUI 상태 복원.
- 수정 `Runtime/BattleController.cs`: 메뉴별 레이아웃·테마 적용, 공통 글꼴, 대사 포트레이트 위치.
- 수정 `Runtime/WeaponSelectionView.cs`: 공통 팔레트·글꼴 선택 사용.
- 수정 `Runtime/CombatPresenter.cs`: 전투 연출 정보 패널·HP/EN·건너뛰기 버튼.
- 신규 `Tests/PlayMode/TacticalThemeTests.cs`: 호버 가독성·버튼 강조·테마 종료 후 GUI 상태 복원 검증.
- 신규 이 안내서와 수정 `고전전술무장선택UI안내.md`.

실제 적용 화면은 프로젝트의 `작업결과/UI/메뉴_*.png`에 저장한다.

## 반격창 통합·전투 확인 폭 고정 변경

- `Runtime/BattleController.cs`: 반격 무장창 열기·취소·결정·입력 연결, 전투 확인 카드 폭 5:5 고정, 무장창과 확인창에 겹치는 맵 표식 숨김.
- `Runtime/WeaponSelectionView.cs`: 공격·반격 공용 화면, 피격 유닛 표시, 반격 사거리·EN·잔탄 검증, 취소 시 대응 보존.
- `Tests/PlayMode/WeaponSelectionViewTests.cs`: 반격 선택·취소·자원 보존·사용 제한 검증 추가.
- `Tests/PlayMode/CombatConfirmationIntegrationTests.cs`: 긴 기체명·무장명에서 실제 렌더링 카드 폭이 같은지 검증 추가.
- 이 안내서와 `고전전술무장선택UI안내.md`, `작업결과/UI/메뉴_반격무장.png`, `작업결과/UI/메뉴_전투확인.png` 갱신.

Inspector 추가 설정은 없다. 씬·프리팹·전투 데이터 에셋은 변경하지 않는다.
