# 스테이지·캠페인 진행

## 제작 순서

1. 기존 맵 에디터로 맵과 유닛 배치를 만들고, 조립형 스크립트 에디터로 인트로·아웃트로를 작성한다.
2. **화성의 용병단 → 스테이지 에디터 → 새 스테이지**에서 이름·인트로·맵·아웃트로를 지정한다. Project의 **Create → 화성의 용병단 → 스테이지**에서도 만들 수 있다.
3. 조건별 다음 경로를 우선순위 순서대로 배치한다. 한 분기 안의 조건은 모두 만족해야 하며, 위에서부터 처음 일치한 분기를 선택한다.
4. 조건이 일치하지 않을 때 사용할 기본 경로를 반드시 지정한다. 마지막 스테이지는 목적지 종류를 **엔딩**으로 설정하고 제목·문구를 입력한다. 빈 스테이지 참조는 설정 오류다.
5. **새 캠페인**을 만들고 첫 스테이지와 시작 자금을 지정한다.
6. 기존 전투 진행기(BattleController)의 **캠페인** 항목에 캠페인 에셋을 지정한다. 이 연결은 Inspector에서 직접 한다. 이번 작업에서는 씬·프리팹에 연결을 저장하지 않았다.

캠페인을 지정하지 않으면 기존 단일 전투를 유지한다. 맵 에디터의 테스트 플레이도 기존처럼 승리·패배 후 종료 버튼을 표시한다.

## 실행 순서

타이틀 → 첫 스테이지 인트로 → 맵 전투 → 아웃트로 → 분기 확정 → 인터미션 → 다음 미션 → 다음 스테이지 인트로.

엔딩 경로가 선택되면 인터미션을 건너뛰고 엔딩 화면으로 전환한다. 엔딩에서 타이틀로 돌아가 새 캠페인을 시작할 수 있다. 패배하면 기존 게임 오버 화면을 사용하며, 재시작은 현재 스테이지의 인트로부터 다시 시작한다.

캠페인에서는 **맵의 시작 이벤트 대신 스테이지 인트로**를 실행한다. 기존 맵 시작 이벤트를 계속 사용하려면 같은 스크립트를 스테이지 인트로에 지정한다. 맵의 진입 이벤트 구역은 그대로 동작한다. 인트로·아웃트로가 비어 있으면 해당 연출을 건너뛴다.

아웃트로에서는 대사·대기·플래그 설정/분기·체력 조건 조회·이벤트 종료를 사용할 수 있다. 전투가 종료된 상태이므로 공격·이동·턴 종료·체력 변경은 설정 오류로 표시한다. 실행 오류가 발생하면 임의로 다음 미션으로 넘어가지 않고 오류 화면에서 재시도하거나 타이틀로 돌아간다.

대사는 기존처럼 클릭·Space·Enter로 넘기며, 파일럿 이름과 포트레이트 선택도 그대로 사용한다.

## 분기 조건

| 종류 | 판정 |
|---|---|
| 플래그 값 | 이름에 해당하는 플래그가 지정한 참/거짓 값과 같음 |
| 클리어 턴 수 이하 | 전투 종료 라운드가 기준 수치 이하 |
| 적 격추 수 이상 | 전투 종료 시 사망한 적군 유닛 수가 기준 수치 이상 |
| 아군 유닛 생존 | 해당 배치 유닛 ID의 아군이 전투 종료 시 생존 |

클리어 턴 수·격추 수·생존 아군 ID는 아웃트로 시작 전에 별도 결과로 기록한다. 플래그는 아웃트로 완료 후 판정하므로 아웃트로에서 설정한 값도 분기에 반영된다. 미설정 플래그는 기존 스크립트와 동일하게 거짓이다.

결정한 다음 스테이지는 인터미션에서 다시 판정하지 않는다. 플래그는 다음 스테이지로 이월한다. 재시작은 현재 스테이지 시작 시점의 플래그로 복원하며, 새 캠페인은 초기화한다.

## 인터미션 기본 화면 범위

공통 회색 패널·남색 제목줄·파란 선택 강조를 사용한다. 상단에 확정된 다음 미션 이름과 보유 자금을 표시한다.

- 기체: 기체 리스트, 기체 개조, 무장 변경.
- 파일럿: 파일럿 리스트, 파일럿 변경.
- 상점: 기체·무장·파일럿.
- 설정: 저장·불러오기·설정·종료.
- 다음 미션: 확정된 다음 스테이지로 출격한다.

이번 구현에서는 진행 구조와 기본 화면을 제공한다. 기체·파일럿 리스트는 완료한 스테이지의 아군 편성 데이터를 읽어 보여준다. 독립적인 보유 인벤토리·전투 간 손상/탄수 이월·개조·무장/파일럿 교체·구매/매각·저장/불러오기는 구현하지 않았다. 해당 메뉴를 선택하면 이용 불가 또는 판매 품목 없음으로 표시한다. 자금은 캠페인의 시작 자금을 표시하며 임의의 보상·수리비·구매 계산식은 도입하지 않는다.

격자 표시·전투 연출·음량 설정과 종료는 동작한다. Editor의 종료는 Play 모드를 끝내고 빌드에서는 애플리케이션을 종료한다. 종료는 자동 저장하지 않는다. 다음 전투는 해당 스테이지 맵의 배치 데이터로 새로 생성한다.

저장/불러오기를 구현할 때는 현재 스테이지·확정된 다음 스테이지의 영구 ID, 자금, 플래그, 보유 기체·파일럿·무장·개조 상태를 함께 저장해야 한다. 현재 진행 상태는 실행 중에만 유지된다.

## 현재 기본 전투 추출 파일

`Assets/MercenariesOfMars/Data/Stage/`에 다음 파일을 추가했다.

- `현재전투_스테이지.asset`: 이름 ‘현재 전투’, 인트로는 기존 `전투_시작안내.asset`, 추출 맵 연결. 기존 기본 전투에는 아웃트로가 없으므로 비워 두고, 기본 경로는 명시적인 엔딩으로 설정했다.
- `현재전투_스테이지_맵.asset`: 10×8칸, 기존 아군 2기·적군 2기의 ID·편성·위치·적군 자동 레벨 설정, 시작 스크립트.
- `현재전투_스테이지_진입불가지형.asset`: (4,3), (4,4), (5,3), (5,4)의 기존 진입 불가 설정을 보존하는 지형.

기체·파일럿·무장·시작 스크립트는 원래 에셋을 참조한다. 값을 복제한 별도 캐릭터 데이터는 만들지 않았다. 씬에는 자동 연결하지 않았으며, 기존 `기동`·`발동` 스테이지도 수정하지 않았다.

다시 추출하려면 **화성의 용병단 → 현재 전투를 스테이지로 추출** 또는 스테이지 에디터의 **현재 씬 전투를 파일로 추출**을 누른다. Play 모드를 종료한 상태에서 실행한다. 기존 파일은 덮어쓰지 않고 새 경로를 사용한다. 캠페인이 연결되어 있으면 첫 스테이지·맵을 복사하고, 연결이 없으면 격자·배치·시작 이벤트를 새 스테이지로 변환한다.

## 스테이지 단위 테스트

1. Play 모드를 종료한다.
2. **화성의 용병단 → 스테이지 에디터**를 연다.
3. 상단 **스테이지 / 캠페인**에 테스트할 스테이지를 드래그한다. 추출한 전투는 `현재전투_스테이지.asset`을 선택한다. Project에서 스테이지를 선택한 뒤 Inspector에서 실행해도 된다.
4. 빨간 설정 오류가 없으면 **스테이지 테스트 플레이**를 누른다.
5. 타이틀을 건너뛰고 선택한 스테이지의 인트로부터 실행한다. 대사는 클릭·Space·Enter로 넘긴다.
6. 승리 후 아웃트로를 끝내면 결과 화면에서 클리어 턴·격추 수·선택된 다음 스테이지 또는 엔딩을 확인한다. 다음 스테이지로 출격하지 않고 멈춘다.
7. **다시 테스트**는 같은 스테이지를 초기 상태로 재실행한다. **종료**는 Play 모드를 종료하고 스테이지 에디터로 돌아간다. 패배 화면에도 다시 테스트·종료 버튼을 제공한다.

전투 중에도 Unity의 Play 버튼 또는 스테이지 Inspector의 **스테이지 테스트 종료**로 끝낼 수 있다. 기존 씬의 루트는 Play 중에만 숨기고, 테스트 종료 후 원래 씬과 Play 옵션을 복원한다. 씬·프리팹 저장은 필요 없다.

단일 스테이지 테스트는 이전 스테이지의 플래그·자금·보유 데이터를 가져오지 않는다. 특정 분기를 확인하려면 해당 스테이지 인트로/맵 이벤트/아웃트로에 기존 **플래그 설정** 명령을 사용한다. 전체 캠페인과 인터미션 이월을 테스트하려면 기존 전투 진행기의 캠페인 항목을 연결하여 일반 Play를 사용한다.

맵 에디터의 **테스트 플레이**는 맵의 시작 이벤트와 전투만 확인하는 기존 기능이며, 스테이지 인트로·아웃트로·분기는 스테이지 테스트를 사용해야 한다.

## 캠페인 플로우 차트

**화성의 용병단 → 캠페인 에디터**를 열고 상단에 캠페인 에셋을 지정한다. 기존 스테이지 에디터에서 캠페인을 선택하거나 캠페인 Inspector에서 **캠페인 플로우 차트**를 눌러도 같은 창이 열린다.

- **플로우 차트** 탭: 첫 스테이지부터 조건별 분기와 기본 경로를 모두 따라가며 스테이지·엔딩을 표시한다. 실제 조건을 판정해 경로를 숨기지 않는다.
- 합류하는 스테이지는 하나의 노드로 표시한다. 이름이 같아도 서로 다른 스테이지 에셋이면 별도 노드다. 엔딩은 경로별로 표시한다.
- 파란 선은 조건 분기, 초록 선은 기본 경로다. 같은 스테이지 사이의 여러 분기도 각각 표시한다. 이전 열로 연결되는 선은 아래쪽으로 우회한다.
- 순환 연결은 노란색과 ‘순환’ 표시로 구분한다. 순환이 있어도 탐색이 무한 반복되지 않는다. 연결 누락·잘못된 목적지는 빨간 오류 노드로 표시한다.
- 연결선에는 분기 이름·조건 요약을 표시한다. 마우스를 올리면 조건 전문을 볼 수 있으며, 스테이지를 선택하면 오른쪽에 모든 경로와 조건을 표시한다.
- 노드 클릭은 상세 정보와 Inspector 선택, 스테이지 노드 더블 클릭 또는 **스테이지 편집**은 기존 스테이지 에디터를 연다. 오류·엔딩 노드에서는 **연결한 스테이지 편집**으로 원본을 수정할 수 있다.
- 빈 공간 드래그·마우스 가운데 버튼으로 이동하고, 휠로 커서 위치를 중심으로 확대/축소한다. **전체 보기** 또는 F 키는 전체 그래프를 화면에 맞춘다.
- **캠페인 설정** 탭에서 첫 스테이지·시작 자금 등을 기존 Inspector와 같은 방식으로 편집한다.
- 연결된 스테이지 설정 변경과 Undo/Redo를 감지해 다시 그린다. **새로고침** 버튼도 제공한다.

차트에서 노드를 끌어 연결하거나 분기 순서를 바꾸지는 않는다. 분기 편집은 원래 스테이지 에디터에서 하며, 캠페인의 첫 스테이지에서 연결되지 않은 에셋은 차트에 포함하지 않는다. Inspector 추가 연결은 필요 없다. 차트 열기·이동·확대·노드 선택은 데이터 에셋을 수정하지 않는다.
