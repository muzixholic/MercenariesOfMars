# 기체·파일럿·유닛 편성

성장 프리셋·능력치 범위·적군 자동 레벨은 [최신 성장 설정 안내](파일럿성장프리셋안내.md)를 참고한다.

## 데이터 구성

전투 유닛은 **기체 + 파일럿 + 진영**의 편성으로 구성한다. 기존 `CharacterDefinition` 에셋은 편성 연결 역할을 맡으므로 씬과 맵의 기존 유닛 참조를 유지한다. 같은 파일럿을 다른 기체로 바꾸거나 같은 기체 정의를 여러 편성에서 사용할 수 있다. 각 전투 유닛의 현재 HP·EN·행동 상태는 별개다.

| 데이터 | 편집 항목 |
|---|---|
| 기체 | 이름, 맵 아이콘, HP, EN, 장갑치, 조준치, 운동성, 이동 가능 지형(지상·공중·우주 복수 선택), 이동력, 가격, 장비 리스트(기존 스킬 에셋을 무장으로 사용), 설명 |
| 파일럿 | 이름, 레벨, 누적 경험치, 공격력, 방어력, 명중력, 회피력, 포트레이트 리스트, 설명 |
| 유닛 편성 | 편성 이름, 기체, 파일럿, 기본 진영 |

파일럿 레벨은 1~99, 공격·방어·명중·회피는 1~999다. 가격은 0 이상 정수이며 화폐 단위와 수리·구매·매각·격추 보상 비율은 정하지 않았다.

누적 경험치는 0 이상 정수로 파일럿 에디터에서 입력하며 전투 상세 능력 화면에도 표시한다. 경험치 획득·필요 경험치·경험치에 따른 자동 레벨업은 아직 없다. 파일럿 레벨과 적군 자동 레벨에 따른 성장 커브는 적용한다. 경험치만 바꾸면 레벨은 바뀌지 않는다. 추가 Inspector 연결은 필요 없다.

## 현재 적용 범위

요청에 따라 **새 기체·파일럿 합산 계산식은 도입하지 않는다**.

- 전투의 최대 HP·EN·이동력·맵 아이콘·사용 무장 목록은 기체에서 읽는다.
- 레벨·공격력·방어력·명중력·회피력과 대사 포트레이트는 파일럿에서 읽는다.
- 기존 피해·명중 계산 구조를 유지한다. 파일럿 공격력+무장 공격력−파일럿 방어력에 기존 지형 보정·대응 규칙을 적용한다. 최종 명중 확률은 기존처럼 0~100%로 제한한다.
- **장갑치·조준치·운동성은 저장·표시만 하며 기존 전투 수치에 더하지 않는다.** 가격을 이용한 비용 계산도 아직 없다.
- **이동 가능 지형 유형도 저장·표시 단계**다. 지상·공중·우주를 기준으로 한 맵 통행 판정, 비행 고도, 바다 횡단, 구조물 비행 통과는 아직 추가하지 않는다. 현재의 맵 이동 불가·이동 비용·점유 규칙을 유지한다.
- 전투 시작 시 수치와 무장을 복사하므로 편집기에서 원본을 바꾸어도 진행 중인 전투 수치는 바뀌지 않는다. 다음 전투에 반영된다.

## 작성 순서

1. **화성의 용병단 → 기체 에디터**에서 기체를 만들고 기체 능력치·맵 아이콘·이동 가능 지형·가격을 설정한다.
2. 장비 리스트의 `+`로 무장 스킬을 지정한다. **화성의 용병단 → 무장 에디터**는 기존 스킬 에디터를 열며, 공격력·사거리·EN 소모·이동 후 사용 여부를 설정한다. 무장 스킬 에셋을 여러 기체가 공유할 수 있다.
3. **화성의 용병단 → 파일럿 에디터**에서 파일럿과 능력치·포트레이트를 만든다. 표정 ID가 유지되어 목록 순서·표정 이름을 바꾸어도 기존 대사의 선택은 유지된다.
4. **화성의 용병단 → 유닛 편성 에디터**에서 기체·파일럿·진영을 조합한다. 새 편성을 만들면 기본 기체와 파일럿도 함께 생성하며, 기존 에셋으로 교체해도 된다. 접힌 기체·파일럿 영역을 펼쳐 직접 편집할 수 있다. 저장 버튼은 편성과 연결된 기체·파일럿 모두 저장한다.
5. 맵 에디터의 유닛 배치에서 편성 에셋을 지정한다. 기체 또는 파일럿만 지정된 불완전한 새 편성은 검증에서 안내한다.

기존 **캐릭터 능력치 에디터** 메뉴도 유닛 편성 에디터를 연다. Unity 에셋 만들기 메뉴에서도 기체·파일럿·유닛 편성을 만들 수 있다. 맵 아이콘·포트레이트 이미지는 Sprite로 임포트해 지정한다.

## 대사 화자

조립형 스크립트의 대사 명령에서 **화자 파일럿**을 선택하면 파일럿 이름을 자동 사용하며 해당 파일럿의 포트레이트를 선택한다. 기체나 전투 편성이 없는 NPC 파일럿도 대사에 쓸 수 있다. 비워 두면 기존처럼 화자 이름을 직접 입력한다.

기존 대사의 캐릭터 화자 참조는 호환 연결로 남겨 둔다. 그 캐릭터가 기체·파일럿으로 분리되면 연결된 파일럿 이름·포트레이트를 읽는다. 기존 표정 ID와 직접 입력 이름을 보존한다. 기존 연결을 해제하거나 화자 파일럿을 새로 지정할 수 있다.

## 기존 데이터 변환

저장된 캐릭터 에셋의 Inspector에서 **기존 데이터를 기체·파일럿으로 분리**를 실행할 수 있다.

- 캐릭터 에셋과 GUID를 유지하고, 같은 폴더 아래 `기체/`, `파일럿/`에 새 에셋을 만든다.
- HP·EN·아이콘·이동력·스킬 목록은 기체로, 레벨·공격·방어·명중·회피·포트레이트는 파일럿으로 복사한다.
- 기존 진영·편성 이름·스킬 참조·포트레이트 ID를 유지한다. 기존 방어 수치는 파일럿 방어력으로 옮긴다. 새로운 장갑·조준·운동성·가격은 0에서 시작해 별도로 입력한다.
- 한 번 변환한 에셋은 다시 실행해도 기체·파일럿을 중복 생성하거나 이미 연결한 데이터를 덮어쓰지 않는다.
- 변환 전 데이터 필드는 호환용으로 남긴다. 새 편성에서는 기체·파일럿 값을 우선 사용한다. 옛 캐릭터 데이터만 있는 경우 기존 전투와 대사를 계속 읽을 수 있다.

이번 작업에서는 프로젝트에 저장된 기존 캐릭터 에셋도 이 방식으로 변환한다. 기존 씬·프리팹은 수정하지 않으며 Inspector의 씬 연결을 다시 할 필요는 없다.
