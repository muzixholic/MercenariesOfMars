# 인터미션 사용 안내

다음 스테이지가 있는 미션을 클리어하면 인터미션으로 이동한다. 마지막 미션의 엔딩 경로는 기존처럼 인터미션을 건너뛴다. 기존의 남색·회색 전술 UI 스타일을 사용하며 씬·프리팹을 추가 연결할 필요는 없다.

## 메뉴

| 메뉴 | 동작 |
|---|---|
| 기체 → 기체 리스트 | 보유 기체, 탑승자, 개조 적용 능력치, 장비, 중량 표시 |
| 기체 → 기체 개조 | HP·EN·장갑·조준·운동성·무장 1단계씩 개조, 비용 확인과 자금 차감 |
| 기체 → 무장 변경 | 장착 무장을 창고로 해제하고 창고 무장을 장착 |
| 파일럿 → 파일럿 리스트 | 대기 파일럿을 포함한 레벨·경험치·현재 능력치·탑승 기체 표시 |
| 파일럿 → 파일럿 변경 | 탑승자 교환, 대기 파일럿 배정, 구매한 미탑승 기체에 배정 |
| 상점 → 기체·무장·파일럿 | 공통·스테이지별·조건부 품목 구매·영입. 매각은 제공하지 않음 |
| 설정 → 저장·불러오기 | 인터미션 상태 3개 슬롯 저장·복원. 타이틀에서도 불러오기 가능 |
| 설정 → 설정 | 음량·격자·전투 연출 변경 및 기기별 설정 유지 |
| 설정 → 종료 | 확인 후 타이틀 복귀 또는 게임 종료 |
| 다음 미션 | 확정된 분기 스테이지로 진입 |

## 다음 미션 출격 수

상단에 다음 스테이지 제목, 자금, 최대 개조 단계와 함께 **선택 출격 가능 수·출격 칸 수·선택 후보 수·고정·강제 출격 수**를 표시한다.

선택 출격 가능 수는 `출격 칸 수`와 `선택 가능한 편성 수` 중 작은 값이다. 다음 스테이지의 출격 준비 스크립트, 영입·이탈, 플래그, 조건부 고정 배치, 강제 교환, 이번 스테이지 선택 제한을 적용해 계산한다. 미리보기는 실제 자금·명단·플래그·현재 전장에 영향을 주지 않는다. 편성이나 장비를 바꾸면 다시 계산한다. 필수 기체·파일럿 미보유 등으로 다음 미션 준비가 실패하면 숫자 대신 확인할 오류를 표시한다.

예를 들어 선택 후보 6기·출격 칸 4개이면 선택 출격 가능 4기로 표시하며, 강제 출격 2기는 별도로 표시한다. 출격 칸이 없으면 선택 출격은 0기이며 맵 지정 고정 아군만 출격한다.

## 개조와 편성

무장 개조 비용은 목표 단계 × 5,000, 나머지 5종은 목표 단계 × 3,000이다. 1단계마다 기본 능력치의 5%를 더하며 현재 캠페인 개조 상한까지만 구매한다. 자금·상한을 검사하고 확인 후 차감한다.

개조·장착·파일럿 교환은 캠페인 실행용 복사본에 적용한다. 원본 기체·파일럿·무장·편성 에셋은 변경하지 않는다. 다음 미션의 고정 배치도 원본 기체·파일럿과 대응되는 복사본을 찾아 사용한다. 현재 진행을 저장하면 복사본의 개조·장비·편성을 복원할 수 있다.

무장 해제는 비용 없이 창고로 돌려보낸다. 같은 무장을 한 기체에 중복 장착할 수 없고 허용중량을 넘으면 장착을 거절한다. 무장 복수 구매는 창고 수량으로 관리하며 다른 기체에 나누어 장착할 수 있다.

파일럿을 다른 탑승 기체에서 가져오면 기존 두 파일럿을 교환한다. 대기 파일럿을 배정하면 기존 탑승자는 대기한다. 미탑승 기체로 기존 파일럿을 옮기면 이전 기체는 보유 목록의 미탑승 상태로 보존한다.

맵의 고정 강제 출격은 미탑승 기체·대기 파일럿도 보유 자원으로 인식한다. 조건부 배치의 보유·영입 조건에도 포함하며, 필요한 조합을 자동 편성하고 확인창 이후 캠페인 편성에 유지한다. 기존 탑승자나 기체는 대기 자원으로 보존한다.

## 상점 데이터 설정

**화성의 용병단 → 스테이지 에디터**에서 스테이지를 선택하고 **클리어 후 인터미션 상점**을 펼친다. 이 목록은 선택한 스테이지를 **완료한 직후**의 인터미션에 적용한다. 다음 미션에 지정한 목록을 미리 사용하지 않는다.

1. **캠페인 공통 판매 목록 포함**: 켜면 기존 캠페인의 판매 목록에 합산한다. 끄면 이 스테이지의 목록만 사용한다. 기존 스테이지는 기본적으로 켜져 있어 기존 상점을 유지한다.
2. **기본 판매 기체·기본 판매 무장·기본 영입 파일럿**: 항상 판매할 품목을 등록한다.
3. **조건부 추가 판매 목록**: 항목을 추가하고 이름·조건·추가 판매 품목을 지정한다. 각 항목 안의 조건을 모두 만족하면 품목을 추가한다. 여러 항목이 일치하면 모두 합산하며 같은 품목은 한 번만 표시한다. OR 조건은 추가 항목을 나누어 작성한다.
4. 가격은 기체의 **가격**, 무장의 **구매 가격**, 파일럿의 **영입 가격**을 사용한다. 0은 무료 품목이다. 임의의 가격이나 판매 목록을 자동으로 지정하지 않는다.
5. 새 기체·파일럿은 대기 상태로 구매한다. **파일럿 변경**에서 기체와 파일럿을 배정하면 선택 출격 후보가 된다.

추가 조건은 다음 두 목록에 넣는다. 두 목록을 함께 사용하면 양쪽 조건을 모두 만족해야 한다. 조건 없는 추가 항목은 설정 오류로 안내하므로 무조건 판매는 기본 목록을 사용한다.

- **클리어·플래그 조건**: 플래그 값, 클리어 턴 수 이하, 적 격추 수 이상, 지정 아군 유닛 ID의 생존. 해당 스테이지 전투 결과를 사용하며 플래그는 아웃트로 실행 후의 현재 값을 사용한다.
- **영입·보유·플래그 조건**: 플래그 참·거짓, 지정 아군의 영입 여부, 기체 보유 여부, 파일럿 영입 여부. 대기 기체·파일럿도 포함한다. 기대값을 끄면 미보유·미영입을 조건으로 사용할 수 있다.

예: 아웃트로에서 `보급기지확보` 플래그를 참으로 설정하고, 추가 목록의 플래그 조건을 `보급기지확보 = 참`으로 지정한 뒤 새 무장을 등록하면 그 인터미션부터 해당 무장을 구매할 수 있다. 구매로 보유 조건이 충족되면 연관 품목도 즉시 표시한다. 조건이 사라지면 구매도 거절하지만 이미 구입한 자원은 유지한다.

**스테이지별 목록은 다음 스테이지로 자동 누적되지 않는다.** 이후에도 판매하려면 이후 스테이지의 추가 목록에도 유지되는 해금 플래그 조건을 등록한다. 저장·불러오기 시 완료 스테이지·전투 결과·플래그·보유 자원을 복원하여 판매 목록을 다시 계산한다.

같은 기체·파일럿 에셋은 캠페인에서 하나의 자원이므로 중복 구매를 막는다. 별개 기체·파일럿을 판매하려면 별도 에셋을 등록한다. 기체 기본 장비는 기체 구매에 포함한다. 상점 무장은 반복 구매할 수 있다. 현재 판매 목록에 없는 품목, 음수 가격, 자금 부족, 잘못된 무장·성장 설정은 구매를 거절한다. **매각은 보류한다.**

## 저장·불러오기

인터미션에서 자금, 현재·다음 스테이지, 확정된 분기, 플래그, 최대 개조 단계, 영입 편성, 미탑승 기체·대기 파일럿, 개조, 장착·창고 무장, 파일럿 레벨·경험치와 이전 전투 결과를 저장한다. 진행 중인 전투 저장은 지원하지 않는다. 저장 슬롯은 3개이며 기존 슬롯 저장과 불러오기는 확인창을 표시한다.

파일은 `Application.persistentDataPath/저장/슬롯1.json` 등의 경로에 저장한다. 덮어쓰기는 임시 파일을 쓴 뒤 교체하며 기존 파일은 `.bak`으로 보관한다. 참조 에셋 누락·지원하지 않는 버전·잘못된 편성·중량·손상 데이터는 현재 진행을 바꾸지 않고 오류로 안내한다. 저장 후 원본 데이터 에셋의 이름이나 폴더를 이동해도 GUID를 유지하면 참조를 찾는다. 에셋 삭제·GUID 변경 시 기존 저장을 읽을 수 없을 수 있다.

빌드에서 안정적으로 에셋을 찾기 위해 `Resources/MercenariesOfMars/저장참조목록.asset`을 사용한다. 에디터의 **화성의 용병단 → 저장 참조 목록 갱신**으로 생성·갱신하며 관련 에셋의 추가·이동·삭제 후 자동 갱신한다. 새 데이터 작성 후 빌드 전에 목록을 갱신한다.
