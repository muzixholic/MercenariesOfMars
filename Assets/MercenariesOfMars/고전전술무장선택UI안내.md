# 고전 전술 패널형 무장 선택 UI

첨부한 1안 기준으로 무장 선택창을 중앙 회색 입체 패널, 남색 제목줄, 파란 선택 행, 표 형식의 무장 수치로 구성했다. Unity UI Canvas를 실행 중에 생성하며 씬·프리팹을 저장하거나 교체하지 않는다.

## 조작

1. 아군 유닛 → 공격을 누른다.
2. 행 클릭 또는 ↑↓로 무장을 살펴본다. Home/End로 처음·마지막 행을 선택한다. 4개를 초과하는 목록은 휠과 키보드 선택에 맞춰 스크롤된다.
3. 결정 버튼 또는 Enter로 확정한다. 창이 닫히고 기존 최소·최대 사거리 규칙대로 공격 범위를 표시한다.
4. 취소·Esc·우클릭은 행동 메뉴로 돌아간다. 창 밖을 클릭하면 유닛 선택을 해제한다.

사용 불가 무장도 선택해 수치를 볼 수 있으나 결정할 수 없다. 잔탄 없음·EN 부족·이동 후 사용 불가 사유를 행과 상세 영역에 표시한다. 미리보기와 취소에는 EN·탄수·행동을 소모하지 않는다. 창 클릭·휠은 맵 클릭·시점 이동으로 전달되지 않는다.

## 표시 데이터와 Inspector 설정

- 상단: 파일럿 이름·레벨, 기체명, HP, EN, 무장 총중량/허용중량, 이동 상태. HP는 빨강·EN은 파랑이다.
- 표: 무장명·공격력·최소/최대 사거리·명중 보정·소비 EN·잔탄·사용 상태. 최대 탄수 0은 ‘제한 없음’으로 표시한다.
- 하단: 선택 무장 이름·설명·무게·이동 후 사용 여부·잔탄 게이지.
- 파일럿 에디터의 **포트레이트 리스트**에서 첫 번째로 이미지가 등록된 표정을 사용한다. 대사창의 표정 선택은 바꾸지 않는다.
- 기체 이미지는 기존 **맵 아이콘**을 사용한다.
- **화성의 용병단 → 무장 에디터 → 무장 이미지**에 스프라이트를 선택하면 행과 하단에 표시한다. 아틀라스·스프라이트 시트도 Unity UI Image로 표시한다.
- 이미지 미지정 시 파일럿·기체·무장 영역에 간단한 대체 표시를 쓴다. 시안의 인물·기체·무장 그림이나 배경 맵은 프로젝트에 가져오지 않았다. 전투 수치는 예제에 맞춰 표시한다.
- 전투 진행기의 **공통 게임 UI 글꼴**은 선택 항목이다. 미지정 시 사용 가능한 한글 시스템 글꼴을 사용한다. 배포할 때는 프로젝트에 포함한 한글 Font를 지정하면 환경에 따른 글꼴 차이를 피할 수 있다.

추가 UI 오브젝트·Canvas·EventSystem을 Inspector에서 연결할 필요가 없다. 기존 Input System 입력을 전투 진행기에서 받아 처리한다. 타이틀·전투 대응·상세 능력·대사창에도 같은 테마를 적용했다. 자세한 내용은 공통게임UI안내.md를 참고한다.

## 반격 무장 선택

전투 대응의 **반격 · 무장 선택**도 공격과 같은 창을 사용한다. 피격 아군의 상태·무장을 표시하며 사거리·EN·잔탄으로 반격 가능 여부를 판단한다. 이전 이동·행동 완료 여부는 반격을 제한하지 않는다. 결정하면 자원을 소모하지 않고 전투 확인으로 넘어간다. 취소·Esc·우클릭·창 밖 클릭은 현재 적 공격을 보존한 채 대응 선택으로 돌아간다. Inspector 추가 설정은 없다.

공격 시에는 현재 위치에서 무장의 최소~최대 사거리 안에 살아 있는 적이 한 기 이상 있어야 결정할 수 있다. 대상이 없으면 행을 비활성 색으로 표시하고 ‘사거리 내 대상 없음’을 안내한다. 상세 수치 미리보기와 취소는 가능하다. 이동 후에는 이동한 위치를 기준으로 다시 판단한다.

아군 행동 메뉴의 공격 버튼도 같은 사용 가능 조건을 사용한다. 사거리·EN·잔탄·이동 후 사용 제한을 모두 만족하는 무장이 없으면 공격 버튼이 비활성화되며 무장 선택창을 열 수 없다. 이동·대기·능력 메뉴는 각각의 기존 조건을 유지한다. Inspector 추가 설정은 없다.
