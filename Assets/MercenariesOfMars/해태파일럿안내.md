# 해태 파일럿 10명

사용자가 제공한 제9독립기동중대 「해태(HAETAE)」 설정을 파일럿 에셋으로 추가했다. 포트레이트 이미지는 넣지 않았다.

## 부대 설정

- 소속: 아르카디아 행성 방위군 제4기동여단.
- 주둔지: 아르카디아 동부 백두산맥 방어기지.
- 주력 병기: TMW-11 「백호」 및 정찰형 TMW-08 「까치」.
- 특징: 산악전·전자전·신속기동에 특화된 한국계 개척민 중심의 부대.
- 발키리와 합동작전명 「쌍성계획」에 참여한다. 발키리는 강습·정밀 타격, 해태는 산악기동·전자전·측면 엄호를 담당한다.

## 기본 능력치

- 레벨 1, 누적 경험치 0.
- 1레벨 공격력 10 / 방어력 3 / 명중력 100 / 회피력 1.
- 99레벨 공격력 108 / 방어력 101 / 명중력 198 / 회피력 99.
- 기존 기본 성장 프리셋을 네 능력치에 연결한다. 생성 시 기본 프리셋은 선형 성장이다.
- 영입 가격은 기본값 0이다. 상점에 판매 품목으로 등록하기 전에 직접 가격을 지정한다.
- 약력의 전문성은 설명으로만 보관하며 전투 수치·고유 능력으로 자동 변환하지 않는다.

## Inspector 설정

1. **화성의 용병단 → 파일럿 에디터**에서 새 파일럿 에셋을 지정하여 능력치·성장 커브·영입 가격을 설정한다.
2. 포트레이트를 준비하면 이미지를 Sprite로 임포트하고 파일럿의 **포트레이트 리스트**에 추가한다. 현재 목록은 모두 비어 있다.
3. 전투에 사용하려면 유닛 편성의 파일럿에 연결하고 캠페인 영입 또는 스테이지 영입 이벤트로 등록한다. 상점에서는 스테이지의 기본/조건부 영입 목록에 등록할 수 있다.
4. 대사만 사용할 때는 조립형 스크립트의 **화자 파일럿**에 지정한다.

새 기체·맵 배치·씬·프리팹·초기 영입·상점 품목은 자동 생성하거나 연결하지 않았다. 이번 추가는 해태 10명이며, 설정을 아직 받지 않은 나머지 10명은 포함하지 않았다.
