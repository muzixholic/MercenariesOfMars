# 캐릭터 이미지·레벨·대사 설정

기체·파일럿 분리 이후에는 맵 아이콘은 기체, 레벨·포트레이트는 파일럿에서 편집한다. 대사의 새 화자 선택도 파일럿을 사용한다. [최신 작성 순서](기체와파일럿안내.md)를 먼저 참고한다. 아래의 캐릭터 연결 설명은 이전 데이터 호환을 포함한다.

## 캐릭터 에디터

Unity 메뉴 **화성의 용병단 → 캐릭터 능력치 에디터**에서 캐릭터 에셋을 지정한다.

- **레벨**: 파일럿에 1~99로 입력한다. [성장 프리셋](파일럿성장프리셋안내.md)에 따라 능력치를 계산하고, 적군은 배치의 자동 레벨 옵션을 사용할 수 있다. 경험치에 따른 자동 레벨업은 아직 없다.
- **맵 아이콘**: Sprite 이미지를 지정하면 전투 격자에서 임시 캡슐 대신 이미지를 표시한다. 미지정 캐릭터는 기존 캡슐을 사용한다. 이미지의 원래 색상을 유지하고 행동 완료 시 어둡게 표시한다. 아이콘은 카메라를 바라보며, 이미지의 가장 긴 변이 약 1.3칸이 되도록 크기를 맞춘다. 아이콘의 중심 피벗을 권장한다. 피격·대기·선택은 기존 격자 클릭 규칙을 따른다.
- **대화 포트레이트 세트**: `+`로 표정을 추가하고 표정 이름과 Sprite 이미지를 지정한다. `−`로 삭제하고 드래그로 정렬할 수 있다. 예: 기본 / 미소 / 분노 / 놀람.

이미지를 Sprite로 사용하려면 해당 이미지의 Unity Import 설정에서 **Texture Type → Sprite (2D and UI)**를 선택하고 Apply한다. 스프라이트 시트도 분할한 개별 Sprite를 지정할 수 있다. 맵 아이콘과 포트레이트는 서로 다른 이미지를 사용할 수 있다. 이미지 에셋과 캐릭터 데이터는 사용자가 지정하며, 기존 씬·프리팹이나 캐릭터 에셋에 임의 이미지를 자동 연결하지 않는다.

## 조립형 스크립트 에디터

**화성의 용병단 → 조립형 스크립트 에디터**에서 대사 명령을 추가한다.

1. **화자 캐릭터（선택）**에 캐릭터 에셋을 지정한다. 현재 전투에 배치되지 않은 NPC도 사용할 수 있다.
2. **화자 이름（자동）**에 캐릭터 이름이 표시된다. 이름은 캐릭터 에셋을 따르므로 이후 캐릭터 이름을 바꿔도 대사에 반영된다.
3. **포트레이트**에서 캐릭터의 표정 중 하나를 고른다. 캐릭터를 처음 지정하거나 다른 캐릭터로 바꾸면 첫 번째 표정을 기본 선택한다. **없음**을 선택하면 이름과 대사만 출력한다.
4. **대사 내용**을 입력하고 저장한다. 실행 시 대사창 왼쪽에 선택 이미지가, 그 옆에 이름과 대사가 표시된다. 이미지 비율을 유지한다. 창 클릭·Space·Enter로 다음 페이지를 넘긴다.

**화자 캐릭터를 비워 두면 화자 이름을 직접 입력**한다. 기존 이름 입력형 대사는 그대로 재생된다. 캐릭터 선택 전 입력했던 직접 입력 이름은 보존하며, 캐릭터를 해제하면 다시 사용할 수 있다.

포트레이트는 목록 번호 대신 고유 ID로 연결한다. 표정의 이름과 순서를 바꿔도 대사의 선택이 바뀌지 않는다. 선택된 표정을 삭제하면 이벤트 검증에서 안내하므로 다른 표정 또는 없음을 다시 선택한다. 이미지가 아직 없는 표정은 이름만 출력한다. 대사 페이지 전환·이벤트 중단·타이틀 전환 시 이전 이미지가 남지 않도록 숨긴다.

## 변경 파일과 Inspector 설정

- 데이터: `Runtime/CharacterDefinition.cs`, `Runtime/EventSequence.cs`, `Runtime/BattleSession.cs`.
- 실행·표시: `Runtime/EventRunner.cs`, `Runtime/BattleController.cs`, 새 `Runtime/DialoguePortraitUI.cs`.
- UI 참조: `Runtime/MercenariesOfMars.Runtime.asmdef`에 기존 설치된 Unity UI 어셈블리 참조 추가.
- 편집기: `Editor/CharacterDefinitionEditor.cs`, `Editor/EventCommandDrawer.cs`, `Editor/EventSequenceEditor.cs`.
- 함께 수정: `Editor/MapEditorWindow.cs`의 마우스 위치에 따른 정보 표시가 레이아웃 오류를 만들지 않도록 정보 줄을 항상 확보한다.
- 검증: 새 `Tests/Editor/CharacterDialogueTests.cs`, 새 `Tests/PlayMode/CharacterDialogueIntegrationTests.cs`, 수정 `Tests/Editor/EventEditorTests.cs`.
- 문서: 이 문서와 `사용안내.md`.

위 경로는 `Assets/MercenariesOfMars/` 기준이다. 새 파일의 Unity 메타데이터를 포함한다. 씬·프리팹에 새 컴포넌트를 수동 연결할 필요는 없다. 포트레이트 표시 UI는 실행 중에 생성된다. **캐릭터 에셋의 레벨·맵 아이콘·포트레이트 목록**, **대사 명령의 화자 캐릭터·포트레이트**만 설정하면 된다.
