# 무장 탄수와 기체 허용중량

## 설정

- **화성의 용병단 → 무장 에디터** 또는 스킬 에디터에서 무장의 최대 탄수·현재 탄수·무게를 설정한다. 세 항목은 0 이상의 정수다.
- **최대 탄수 0**: 잔탄 개념 없이 사용한다. EN 소비와 이동 후 사용 제한은 기존처럼 적용한다.
- **최대 탄수 1 이상**: 현재 탄수는 0~최대 탄수이며 전투 시작 시 잔탄으로 사용한다. 최대 탄수를 늘렸다고 자동 장전하지 않으므로 현재 탄수도 설정한다.
- **화성의 용병단 → 기체 에디터**에서 허용중량을 지정한다. 총 무장 무게가 허용중량 이하일 때만 새 무장을 추가·교체할 수 있다. 총중량/허용중량도 표시한다.
- 같은 무장 에셋은 한 기체에 한 번만 장착할 수 있다. 에디터의 중복 선택과 코드의 중복 추가를 거절하며, 외부에서 중복 등록한 편성도 검증과 전투 시작에서 차단한다. 서로 다른 기체는 같은 무장을 사용할 수 있다.
- 무장 무게 기본값 0, 최대 탄수 기본값 0, 기체 허용중량 기본값 100이다. 기존 무장 구성과 탄수 제한 없는 동작을 유지한다.

## 전투 동작

공격과 반격이 실제 실행되면 1발 소비한다. 빗나가도 소비한다. 선택·전투 확인·취소·실패에는 소비하지 않는다. 공격에 먼저 격추되어 반격하지 못하면 반격 탄수는 그대로다. 잔탄 0 무장은 공격·반격 선택과 적 AI 사용 후보에서 제외한다. 턴이 바뀌어도 재장전하지 않는다.

무장 에셋의 현재 탄수는 전투 시작값이며 진행 중 잔탄은 각 유닛의 `BattleSkill.CurrentAmmo`에 저장한다. 같은 무장을 쓰는 다른 유닛과 탄수를 공유하지 않으며 원본 에셋을 수정하지 않는다. 다시 시작하면 설정한 시작 탄수로 복원한다. 공격·반격 선택창, 전투 확인, 상세 능력창에 잔탄을 표시한다.

중량은 무장 목록 슬롯별로 합산한다. 무장 무게를 나중에 바꾸거나 허용중량을 낮춰 기존 편성이 초과 상태가 되면 에디터에 오류를 표시하고 맵 검증·전투 시작을 막는다. 무장을 자동 삭제하지 않으므로 직접 제거하거나 허용중량을 조정한다. 허용중량 0 기체에는 무게 0 무장만 장착할 수 있다.
