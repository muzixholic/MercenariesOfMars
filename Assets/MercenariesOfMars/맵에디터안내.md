# 맵 에디터 사용 안내

현재 유닛 배치는 기체·파일럿을 연결한 **유닛 편성 에셋**을 사용한다. 기존 캐릭터 참조는 편성으로 유지되므로 맵을 다시 연결할 필요가 없다. [기체·파일럿 설정](기체와파일럿안내.md)을 참고한다.

바로 살펴볼 예제는 `Assets/MercenariesOfMars/Data/맵예제/지형예제맵.asset`이다. 선택 후 Inspector의 **맵 에디터에서 열기** 버튼을 누른다. 평지·숲·늪·바다, 2×2 바위, 기존 캐릭터 4명과 숲 진입 안내 이벤트를 포함한다. 예제는 기존 씬에 연결되어 있지 않다.

## 작성 순서

1. Unity 메뉴 **화성의 용병단 → 맵 에디터**에서 **새 맵**을 만든다. 맵은 씬과 별개의 전투 맵 에셋이다.
2. **맵 설정**에서 이름, 가로·세로 크기(각 1~64), 칸 크기, 기본 지형을 정한다. **기본 지형 세트 만들기**로 평지·숲·늪·바다 에셋을 만들 수 있다. 기존 에셋과 이름이 겹치면 새 이름으로 만든다.
3. 위쪽 **지형 칠하기** 도구와 왼쪽 **도구** 탭에서 지형 에셋을 고른다. 좌클릭·드래그로 칠한다. 우클릭하면 기본 지형으로 복귀한다. 기본 지형 미지정 시 비용 1, 보정 0의 평지다.
4. **구조물 배치** 도구에서 구조물 정의를 만들고 배치한다. 기준 칸에서 오른쪽·위쪽으로 지정한 칸 수를 차지한다. 청록 미리보기는 배치 가능, 빨강은 배치 불가다. 우클릭은 구조물 전체 삭제다. 구조물 삭제는 지형을 바꾸지 않는다.
5. **유닛 배치** 도구에서 기존 캐릭터 에셋과 유닛 ID 접두어를 지정하고 빈 칸을 클릭한다. 진영은 캐릭터 정의를 따른다. 같은 ID는 숫자를 붙여 구분한다. 아군·적군을 각각 한 명 이상 둔다. 우클릭은 유닛 삭제다.
6. **이벤트 구역** 도구에서 조립형 이벤트 에셋을 고른 후 직사각형을 드래그한다. 아군이 영역 안에 있으면 전투당 한 번 실행한다. 다른 이벤트·전투 확인·연출 중에는 대기한다. 시작부터 영역 안에 있는 아군도 발동한다. 이벤트 종료 후 다시 발동하지 않으며, 전투 재시작 시 초기화한다. 우클릭은 그 칸을 포함하는 구역을 삭제한다.
7. 승리 조건은 **적 전멸** 또는 **아군 목표 칸 도달**이다. **목표 칸** 도구로 클릭하면 도달 조건으로 바뀐다. 우클릭하면 적 전멸로 돌아간다. 도달 조건에서는 적을 모두 쓰러뜨려도 목표 도달 전까지 진행한다. 아군 전멸은 항상 패배다. 시작 이벤트는 맵 설정에서 지정한다.
8. **검증** 탭에서 오류와 도달성 경고를 확인하고 **검증 후 저장**한다. 작성 중인 불완전한 맵은 **초안 저장**으로 보관한다.
9. **테스트 전투**로 실행하고 Unity Play 종료 또는 **테스트 종료**로 편집에 돌아온다.

맵 에디터의 테스트 전투에서 승리하거나 패배하면 결과 화면에는 **종료** 버튼만 나온다. 누르면 Play 모드를 끝내고 맵 에디터로 돌아온다. 일반 전투에서는 기존 **다시 시작 / 타이틀로 돌아가기** 버튼을 사용한다. 이 구분은 테스트 생성 시 자동으로 연결되므로 Inspector 설정은 필요 없다. 관련 변경 파일은 `Runtime/BattleController.cs`, `Editor/MapBattlePreview.cs`, `Tests/PlayMode/GameOverTests.cs`다.

## 지형 규칙

지형 정의는 맵 에디터 도구 탭 또는 에셋 Inspector에서 편집한다. 공유 지형 에셋을 바꾸면 이를 사용하는 모든 맵에 적용되며, 이미 시작한 전투의 격자 수치는 유지된다.

| 기본 세트 | 이동 가능 | 진입 비용 | 공격 명중 보정 | 피격 방어력 보정 |
|---|---|---|---|---|
| 평지 | 가능 | 1 | 0 | 0 |
| 숲 | 가능 | 2 | -5%p | +2 |
| 늪 | 가능 | 3 | 0 | 0 |
| 바다 | 불가 | 1(현재 진입 불가) | 0 | 0 |

이 값은 예시이며 자유롭게 바꿀 수 있다. 이동 비용은 목적지 칸에 들어갈 때 소모하고 출발 칸 비용은 차감하지 않는다. 경로는 이동 비용 합이 가장 작은 경로를 사용한다. 다른 유닛과 이동 차단 구조물은 통과하지 않는다. 지형 또는 구조물 중 하나라도 이동을 막으면 진입할 수 없다.

- 최종 명중률 = 캐릭터 명중 + 스킬 명중 보정 + **공격자가 서 있는 칸의 명중 보정** − 대상 회피. 0~100%로 제한한다.
- 피해 = 최대(1, 캐릭터 공격 + 스킬 공격력 − 대상 방어 − **피격자가 서 있는 칸의 방어 보정**).
- 반격도 같은 계산을 사용하며 공격자·피격자 역할이 바뀐다.
- 방어 대응은 위 피해를 절반으로 줄여 올림한다. 회피 대응은 위 명중률을 절반으로 줄인다.
- 방어 보정은 고정 수치이며 음수도 허용한다. 백분율 감소가 아니다.

## 표시·편집

- 격자 표시를 지형색 / 이동 비용 / 명중·방어 보정 / 이동 불가로 전환한다. 칸 확대 슬라이더와 스크롤로 맵을 확인한다. 세로 좌표는 아래에서 위로 증가한다.
- 이동 미리보기에서 유닛을 클릭하면 해당 캐릭터 이동력, 빈 칸을 클릭하면 임시 이동력으로 범위를 표시한다. 다른 유닛 점유를 반영한다. Esc로 해제한다.
- 배치 탭에서 유닛 ID, 좌표, 구조물, 이벤트 영역 및 칠한 지형 목록을 직접 수정할 수 있다.
- 칠하기 한 번의 드래그는 한 번의 실행 취소로 복원한다. Ctrl/Cmd+Z와 다시 실행을 지원한다.
- 맵을 줄여도 밖에 놓인 데이터는 자동으로 지우지 않는다. 검증 후 배치 탭에서 수정한다.
- 구조물은 이동을 막는 장애물 또는 이동을 허용하는 장식으로 정한다. 두 경우 모두 편집상 같은 칸에 구조물·유닛을 겹쳐 배치하지 않는다.
- 지형은 색 또는 선택 재질로 표시한다. 구조물은 선택한 프리팹을 원본 수정 없이 실행 중 복제한다. 프리팹 미지정 시 칸 크기와 높이에 맞춘 임시 상자를 사용한다. 프리팹의 원점은 바닥 중앙이며 자체 크기를 사용한다.

## 검증과 테스트

오류: 크기, 누락된 캐릭터·진영, ID 중복, 이동 불가 시작점, 유닛·구조물 겹침, 구조물 범위 이탈, 잘못된 지형 항목, 이벤트 누락·잘못된 명령, 이벤트 영역 범위 이탈, 이동 불가 목표 칸.

경고: 아군 시작점에서 걸어서 도달할 수 없는 적군·목표 칸·이벤트 구역. 도달성 검증은 유닛 점유를 제외한 지형·구조물을 기준으로 한다. 격리된 적을 원거리로 공격하는 설계는 경고를 검토한 뒤 유지할 수 있다.

테스트 전투는 편집 중인 씬의 루트를 **실행 중에만** 숨기고 임시 보드·카메라·조명·전투 진행기를 생성한다. 기존 씬과 프리팹 에셋을 저장하지 않는다. Play 종료 시 원래 편집 상태로 복귀한다. 편집 상태 복원을 위해 테스트에 한해 **씬 다시 불러오기**를 켜고, 종료 후 기존 Play 모드 옵션을 복원한다. 테스트 전투는 기존 시작 대사·대응·연출·승패 UI를 사용한다.

## 실제 씬에서 사용하려면

기존 씬에는 이번 작업으로 아무 맵도 자동 연결하지 않는다. 맵 에디터의 테스트 전투는 Inspector 연결 없이 이용할 수 있다.

사용자가 실제 씬에 적용할 때는 **GridBoard → 맵 데이터**에 만든 맵 에셋을 넣는다. 맵이 지정되면 보드 크기·칸 크기·지형·구조물·유닛 배치·시작 이벤트는 맵 데이터를 사용한다. 기존 보드의 진입 불가 목록과 전투 진행기의 수동 유닛 배치는 맵 데이터가 없는 경우에 사용한다. 기존 바닥·장식·장애물 모델은 자동으로 지우지 않으므로, 실제 씬 연결 작업 때 중복 모델을 정리한다. 연결·정리는 별도 승인을 받고 진행한다.

## 구현 계획과 후속 범위

현재 단계: 지형 정의 → 가중 이동 계산·전투 보정 → 맵 저장·읽기 → 격자 칠하기 → 다칸 구조물 → 유닛·이벤트·승리 조건 → 검증·테스트 전투.

후속 단계: 고저차, 비행·수상 등 이동 유형, 구조물 파괴, 구조물 회전, 공격 차단·시야 판정, 더 다양한 승패 조건, 3D Scene 뷰에서 직접 칠하기. 지금의 맵 편집 화면은 평면 격자이고 실제 전투는 3D다. 이동 차단은 공격 차단에 적용되지 않으며, 스킬의 최소·최대 맨해튼 거리 규칙을 유지한다.
